# ターフライド プライバシーポリシー

対象：iOS・TestFlightテスト版　最終更新日：2026年11月7日

## 運営者と適用範囲

ターフライドの開発者は、本テスト版について以下のとおり情報を取り扱います。お問い合わせは[問い合わせフォーム](https://docs.google.com/forms/d/e/1FAIpQLSfDXdjFAEyPFgGy_vWP1-3iDECeUq8MQjU7MNGlYQa2KITDtw/viewform)からお送りください。

## ゲーム内の保存データ

騎手名、勝負服、所有馬、育成・レースの進行や成績、ゲーム内ポイント、画質・操作設定を、お使いの端末内に保存します。ゲームの続きや設定を復元するために使います。騎手名に実名を入力する必要はありません。

ゲーム本体は、この保存データを開発者のサーバーへ自動送信しません。現在、ゲーム用アカウント登録、サーバーへのセーブ同期、広告、広告目的のトラッキングはありません。Unity Analyticsによるゲーム利用状況の収集も使用していません。

端末内のデータは、OSの「Appを削除」などで削除できます。OSが行うバックアップとその削除は、OS側の設定に従います。開発者は端末内の保存データを遠隔で取得・削除できません。

## 任意の性能計測

開発用の計測を有効にすると、フレーム時間・メモリ使用量・OSやGPU等の端末情報・画面解像度・ビルド番号・レース条件を含む計測ログを端末内に記録します。このログは自動送信されません。「コピー」は端末のクリップボードへ書き込みます。共有する場合は、ご自身で内容を確認して送信してください。計測画面の「計測の記録を消す」から保存済みの計測ログを削除できます。

## 問い合わせフォーム

お問い合わせにはGoogleフォームを使用します。送信した問い合わせ内容と、任意で記入した返信先などの情報を開発者が受け取り、返信、不具合の調査、ゲームの品質改善に限って使用します。氏名や電話番号の記入は不要です。本文には必要のない個人情報を書かないでください。

フォームへの回答にGoogleアカウントへのログインは必要ありません。フォームの設定によってメールアドレスを自動収集することはなく、返信を希望する場合にだけ返信先を任意で記入できます。回答の概要は他の回答者へ公開しません。返信先を記入しなかった場合は、個別の返信ができません。

Googleは、フォームの提供・回答の保管等のために情報を処理します。また、フォームを開いた際のアクセス情報等はGoogleのサービスとして取り扱われます。Googleによる情報の収集・管理については、[Googleプライバシーポリシー](https://policies.google.com/privacy?hl=ja)をご確認ください。フォームの利用によって、ゲームの保存データが自動で送信されることはありません。

## TestFlightが扱う情報

TestFlightでは、Appleがクラッシュログや利用状況、端末・OS・アプリのバージョン等を自動収集し、開発者に共有します。TestFlightから送信したコメントやスクリーンショット等のフィードバックも、Appleを通じて開発者へ届きます。招待方法等により名前やメールアドレスが含まれる場合があります。公開リンクだけで参加した場合、招待情報としての名前・メールアドレスは開発者に表示されません。

開発者はこれらを本アプリの不具合調査・品質改善に限って利用し、第三者へ共有しません。Appleによる収集・保存や、利用者が管理できる情報については、[Apple「TestFlightとプライバシー」](https://www.apple.com/legal/privacy/data/ja/test-flight/)をご確認ください。

## 保管・削除と第三者への提供

開発者が受け取った問い合わせ・フィードバック・計測資料は、対応や不具合の調査・改善に必要な期間だけ保有し、不要になったものから削除します。法令上の保存義務がある場合は、その期間に従います。AppleやGoogleが各サービスのために保管する情報の取り扱いは、それぞれの方針によります。

個人情報を販売したり、広告目的に利用したりしません。問い合わせフォームの受付・保管にはGoogleが、個別の返信には使用するメールサービスが関与します。これらのサービスの利用のほか、本人の同意がある場合または法令に基づく場合を除き、受け取った情報を第三者へ提供しません。TestFlightから受領する情報については、上記のTestFlightの条件に従います。

開発者が保有する情報の確認、訂正、削除のご希望も、[問い合わせフォーム](https://docs.google.com/forms/d/e/1FAIpQLSfDXdjFAEyPFgGy_vWP1-3iDECeUq8MQjU7MNGlYQa2KITDtw/viewform)からご連絡ください。対象とご本人との関係を確認したうえで対応します。
